# firstome.com

퍼스트옴(Firstome) 홈페이지. GitHub Pages로 `main` 브랜치 루트를 그대로 배포합니다. 빌드 과정은 없습니다.

| 주소 | 파일 | 내용 |
| --- | --- | --- |
| https://firstome.com/ | `index.html` | 회사 소개, 세 사업, 퍼스트옴 Dx |
| https://firstome.com/samplo/ | `samplo/index.html` | 샘플로 (전처리 · 실시간 추적 · 바이오뱅킹) |
| https://firstome.com/omicsmate/ | `omicsmate/index.html` | 오믹스메이트 (AI 분석 매칭) |

- `CNAME`: 사용자 도메인 `firstome.com`
- `.nojekyll`: Jekyll 처리 없이 파일을 그대로 배포
- 접수 폼은 아직 연결하지 않았습니다. 버튼은 "온라인 접수 준비 중"으로 비활성화되어 있고 아무 데이터도 전송되지 않습니다.
- 가격은 공개하지 않습니다. 품질 체계는 "GCLP에 준하는"으로 표기합니다 (인증 아님).
